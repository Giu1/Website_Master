# Lucas Bastos — portfolio

Four-page portfolio (Home, Work, About, Contact) for Lucas Bastos. Vanilla HTML/CSS/JS, no dependencies.

## What it does

- **Page transitions:** every link between the four pages raises a dark panel with a bowed top edge, names the next page ("• Contact"), then navigates under it. The new page opens behind the same panel, which lifts off with a bowed bottom edge while the heading rises in. The Hello loader only plays on a direct visit.
- **Loader:** a short run of greetings, then the dark panel lifts away with a bowed edge.
- **Hero:** a full-height photo whose sides fade into a colour sampled from that photo, "Located in Portugal" pill with a turning globe, and the name looping across the bottom. The loop speeds up while you scroll and flips direction when you scroll back up.
- **Photo switcher:** the thumbnail pill in the hero crossfades between the 7 photos and shifts the hero colour to match. The pick is remembered in this browser (`localStorage`, key `lb-photo`).
- **Smooth scroll** on desktop (the page eases toward the scroll position). Phones and reduced-motion use native scroll.
- **Magnetic buttons:** round buttons and top links lean toward the pointer and spring back. Round buttons fill blue from the bottom on hover.
- **Menu:** a round button appears once the top bar scrolls away. It opens a dark side panel whose bulging edge straightens as it lands.
- **Intro:** the sentence rises in word by word.
- **Work list and Work page table:** hovering a row shows a preview that trails the pointer, with a blue "View" dot. Rows link to the matching case in `../folio/`.
- **About:** heading, round arrow button on a rule, story and photo, three services.
- **Contact:** numbered form (stays on the page; it validates and thanks you, but sends nothing), contact and business details.
- **Sliding rows:** two rows of project tiles drift in opposite directions as you scroll.
- **Footer:** a white curve flattens into the dark footer. "Get in touch" button, email and phone pills, live Lisbon clock.

## Languages

English and Portugal Portuguese. The EN / PT toggle sits in the top bar and in the menu. The choice is saved in `localStorage["portfolio-lang"]`, the same key the other demo sites use; a first visit follows the browser language. Page titles, transition labels, the loader's first greeting, form messages, image alt text and the clock (12 h in EN, 24 h in PT) all switch.

`js/i18n.js` is the shared helper copied from the other sites (keep it identical). `js/lang.js` is generated.

## Build

The four pages and `js/lang.js` are generated by `build.py` from one string table (`S`), where every entry is `(English, Portuguese)`. Change text there, then run `python build.py` (Python 3.12+). Editing the HTML directly works too, but the next build overwrites it.

## Edit

| Change | Where |
| --- | --- |
| Any text (both languages), links, email, phone | `S` and the page templates in `build.py`, then `python build.py` |
| Page names on the transition panel | the `nav.*` keys in `build.py` |
| Work list / table previews | `data-preview` (image) and `data-bg` (colour) on each link |
| Greetings in the loader | `GREETINGS` in `js/main.js` |
| Colours, sizes | `:root` in `css/style.css` |
| Hero photos | `img/hero/lucas-N.jpg` (1333×2000) + `lucas-N-thumb.jpg`. Each switcher button carries `data-photo` and `data-bg` (backdrop colour). |

Project names, the email address, phone, socials and the contact form are placeholders. The full-size originals live in the repo's root `img/` folder and are git-ignored; only the web-sized copies here are published.
