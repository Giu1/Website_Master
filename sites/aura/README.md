# Aura

Complete fictional salon in Chiado. Cream, Newsreader + Figtree.

**Pages:** `index.html` · `services.html` · `team.html` · `gallery.html` · `booking.html` · `contact.html`

Reads `localStorage["aura-demo-store"]` via `js/store.js` (must match `aura-desk/js/store.js`). Home announce/hero/hours, services, team, gallery, and booking select are painted in `js/main.js` and refresh on `langchange`.

Default English names map to i18n keys (`svcCut`, `roleColour`, `closed`, day keys). Edited desk copy stays as stored.
